# 木桶结冰（重做）

> 作者回忆以前做过这个机制（代码遗失后找不回），按描述重做。原模组 2.3.2beta 没有这个机制。

## 规则
- **结冰**：木桶里装满 1 桶水，所在高度 **Y ≥ 120**、亮度 **≤ 7** 时开始结冰，**120 秒**结成整块冰。
- **取冰**：完全结冰后右键取出 1 个冰块，木桶变空。
- **融化**：方块光 **≥ 12**（与原版冰融化的条件一致）时开始融化，**120 秒**变回 1 桶水。结冰过程中条件不满足时进度倒退（同样按 120 秒的速度）。
- 结冰中 / 已结冰的木桶不接受堆肥、液体、粗盐等其他操作。

## 外观
液面用原版霜冰（`textures/blocks/frosted_ice_0..3`）的四帧碎裂贴图：结冰时倒着播放（细碎裂纹 → 冰慢慢合拢成完整的冰面），最后换成冰的贴图；融化时正着播放。贴图是原版自带的，不需要自己画。

## 依据
原版的温度随高度降低（高处的水会结冰、下雪），冰在方块光大于 11 时融化。
