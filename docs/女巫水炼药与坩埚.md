# 女巫水炼药与两种坩埚的分工（策划稿）

> 来源：作者的《女巫水炼药（讨论稿）》+ 后续确认。规则已定稿，时间等数值为初稿。

## 1. 两种坩埚的分工

| | 木坩埚 | 陶瓷坩埚（加热） |
|---|---|---|
| 定位 | **常温**的液体加工 | **加热**相关的一切 |
| 现有功能 | 树苗 / 树叶化成水 | 圆石 / 石头 / 沙砾熔成岩浆 |
| 新增功能 | **女巫水炼药** | 作为**烧结窑**的核心（烧结只在窑里进行）；导热更快的坩埚另行合成 |
| 工作模式 | 化水 / 炼药，互斥 | 熔化 / 烧结（在窑里），互斥 |

**互斥规则**：模式由第一件放进去的东西决定；要换模式，先把里面清空。

**容量调整**（现在能装太多液体）：两种坩埚都改为**最多 1 桶**，与原版炼药锅一致。陶瓷坩埚原来能存 10 桶岩浆，改小后需要更勤地取出——以后的自动化、液体炼矿会在这个基础上设计。

## 2. 女巫水炼药

### 2.1 设计目标
- 让 S4 在不去下界的前提下拿到**虚弱药水**，治愈僵尸村民，打开村民线；
- 只出**负面效果**；正面药水仍然走酿造台和下界，不替代原版酿造；
- 是"捷径"，必须有成本：比酿造台更费材料、更慢。

### 2.2 流程
1. 木坩埚里装 1 桶**女巫水**；
2. 放入**效果材料**（决定药水种类）；
3. 可选：放入**修饰材料**（决定时长 / 等级）；
4. 静置（**不需要热源，不需要燃料**），约 30 – 60 秒后成药；
5. 用**玻璃瓶**取出：每瓶用掉 1/3 桶，1 桶出 3 瓶；取完坩埚变空，**女巫水被消耗**。

产出**全部是喷溅型**（原版的女巫就是投掷喷溅药水），直接用 `Potions.resolve(效果, 'ThrownSplash')` 生成原版药水物品——已实测：喷溅虚弱药水砸中僵尸村民 + 金苹果能正常治愈。

### 2.3 配方

**效果材料**（一锅只能有一种效果）：

| 材料 | 药水 |
|---|---|
| 发酵蛛眼 | 虚弱 |
| 蜘蛛眼 | 中毒 |
| 史莱姆球 | 缓慢 |

**修饰材料**（与原版规则一致，二选一）：

| 材料 | 作用 | 对应的原版药水 |
|---|---|---|
| 红石 | 延长时间 | 长效虚弱 / 长效中毒 / 长效缓慢 |
| 萤石粉 | 提升等级 | 剧毒（中毒 II）、缓慢 IV；虚弱没有加强版，放萤石粉无效 |

时长和等级只能取原版已有的药水变体，不能自由设定（技术限制）。

### 2.4 自由度：参考原版的炼药废案，只取一小层
Beta 1.9 预发布版 2 里，药水是在炼药锅里加水再依次放材料做成的：材料组合对了得到正面效果，组合错了就叠上负面效果；那套系统复杂、没有界面、会出现大量重复的药水，后来被酿造台取代。（见 Minecraft Wiki 的"酿造"条目）

这里只保留它最有意思的一点——**放材料的顺序和组合会影响结果，而且会"放错"**：

| 当前状态 | 放入 | 结果 |
|---|---|---|
| 女巫水 | 效果材料 | 对应的药水（未完成，静置后成药） |
| 某种药水 | 红石 / 萤石粉 | 对应的长效 / 加强版 |
| 长效药水 | 萤石粉 | 变成加强版（与原版一样，失去长效） |
| 女巫水 | 红石 / 萤石粉（放早了） | **失败反应** |
| 某种药水 | 另一种效果材料（两种效果打架） | **失败反应** |
| 任何状态 | 其他物品 | 放不进去 |

**失败反应**（作者决定：不做"浑浊的水"——附加包的液体系统不好用）：放错的那一刻起就不能再放东西；锅里发生一段反应——冒泡、冒烟的粒子，伴随嘶嘶声——几秒后整锅液体**直接蒸发**，坩埚变空，材料全部损失。

### 2.5 成本口径
- 原版酿造台：1 份材料出 3 瓶，约 20 秒，要烈焰粉当燃料；
- 女巫水炼药：1 桶女巫水（菌丝上约 50 秒）+ 1 份效果材料出 3 瓶，约 30 – 60 秒；只能出负面、只有喷溅型。

所以在能用酿造台时，它并不更划算；它的价值是"在去下界之前就能做"。

## 3. 前置依赖（都在体系内）

| 需要 | 来源 | 状态 |
|---|---|---|
| 女巫水进木坩埚 | **只能在木桶里生成**（满桶水 + 下方菌丝，约 50 秒），再用桶舀到木坩埚：新增**女巫水桶**（铁桶）和**陶瓷女巫水桶**（陶瓷桶），舀出、倒入与水桶相同 | 已定，待做 |
| 发酵蛛眼 | 蜘蛛眼（诅咒之土）+ 棕色蘑菇 + 糖 | 棕色蘑菇：孢子对着菌丝右键长出（待做） |
| 僵尸村民 | 诅咒之土生成僵尸时按 5% 替换 | 待做 |
| 金苹果 | 金锭 ×8 + 苹果 | ✅ |

## 4. 铜绿线采用同一套方案
- 木桶：女巫水 + 铜绿粉 → **净化巫水**（铜绿粉被消耗）；
- 木坩埚：以**净化巫水**为底液，按同样的流程（效果材料 → 可选修饰 → 静置 → 玻璃瓶取出）做铜绿系药水；
- 铜绿系药水的种类和效果待定。

**技术提醒**：如果铜绿系药水的效果不是原版已有的，就不能用 `Potions.resolve` 直接生成原版药水，需要自定义投掷物品，命中时由脚本施加效果——可以做，但比原版药水麻烦，定效果时要考虑这一点。

## 5. 为以后做的铺垫
- 木坩埚变成"**底液 + 材料 → 产物**"的通用常温容器：以后加别的底液、别的配方，只需要往表里加行；
- 陶瓷坩埚专注加热，容量收到 1 桶，为烧结窑、液体炼矿留出结构；
- 两种坩埚都有"工作模式"的概念，和木桶的状态互斥一致。

## 6. 状态

全部已定：两种坩埚最多 1 桶；女巫水只能在木桶生成、用桶转移；放错材料 → 失败反应 → 整锅蒸发。
